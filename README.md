# 財務AIダッシュボード (Life Science Financial AI Dashboard)

`aidash` と `bidash` を統合し、Python（Streamlit + Plotly）ベースのモダンなインタラクティブWebアプリケーションとして再構築した財務分析システムです。

損益計算書（P/L）、貸借対照表（B/S）、複数期サマリーのCSVから、直感的なダッシュボードと **Hugging Face Inference API によるAIアナリストコメント** を自動生成します。

---

## 🌟 主な機能一覧

### 1. `bidash` 移植機能
- **業績サマリー**:
  - 当期売上高、売上総利益率、営業利益率、当期純利益率、自己資本比率、ROE のKPIカード（前期比YoY表示付き）
  - 売上高・利益トレンド複合グラフ（棒＋折れ線）
  - ROE・自己資本比率推移グラフ
  - EPS（1株当たり利益）推移
- **損益計算書 (P/L) 分析**:
  - 利益構造ウォーターフォール（Waterfall）
  - 利益率比較（前期 vs 当期 水平バー）
  - 費用構造円グラフ（原価・販管費・営業利益のドーナツチャート）
  - 損益計算書 詳細データテーブル（増減額・増減率の自動算出）
- **貸借対照表 (B/S) 分析**:
  - 資産構成の変化（流動・固定の内訳スタックバー）
  - 負債・純資産構成の変化（スタックバー）
  - 財務健全性指標（流動比率、自己資本比率、負債比率、ROA、ROE）
  - 総資産・純資産トレンド
  - 貸借対照表 詳細データテーブル

### 2. `aidash` 移植機能
- **Hugging Face Inference API 連携**:
  - 業績サマリー、P/L、B/S の各観点から、証券アナリスト視点の日本語コメントを自動生成
  - 推奨モデル選択（Mistral-7B, Qwen2.5-7B, Gemma-2-2B, Llama-3.2-3B 等）およびカスタムモデル指定に対応
  - セキュアなトークン設定UI（環境変数 `HF_API_TOKEN` からの自動読み込みにも対応）

### 3. 本アプリ限定の強力な新機能 🚀
1. **ワンクリック・サンプルデータ読み込み**:
   - CSVファイルを用意していなくても、画面上のボタン1つで「株式会社サンプルテック (9999)」のデータをロードして即座に体験可能。
2. **オフライン自動財務診断エンジン（APIトークン不要）**:
   - HFトークン未設定時や通信エラー時でも、収益性・安全性・成長性・効率性の4軸で100点満点スコアリングとS/A/B/C/D判定、プロの財務アナリスト同等の診断コメントを即座に出力。
3. **デュポン分析（DuPont Analysis）**:
   - ROEを「売上高純利益率（収益性）× 総資産回転率（効率性）× 財務レバレッジ（資本構成）」の3要素に分解して、収益力改善のドライバーを可視化。
4. **損益分岐点（BEP）＆経営安全余裕率分析**:
   - 固変分解に基づく損益分岐点売上高と安全余裕率を算出し、売上減少に対する経営耐性を判定。
5. **経営What-Ifシミュレーター（感応度分析）**:
   - スライダーで「売上高変動率」「原価率改善幅」「販管費増減率」を操作し、翌期の営業利益や利益率への影響をリアルタイムにシミュレーション。
6. **画面上でのリアルタイムデータ直接編集（Data Editor）**:
   - アップロードしたCSVやサンプルデータをWeb画面上で直接編集・更新し、即座にすべての分析に反映。
7. **実在企業の財務データ自動取得 (yfinance連携)**:
   - 4桁の銘柄コード（例: `7203`, `4502`, `6758` 等）や企業名を入力、または代表銘柄を選択するだけで、上場企業の実財務諸表データを即座に取得・可視化。
8. **スタンドアロンHTMLレポート出力**:
   - オフラインでもブラウザ単体で閲覧・共有できる、インタラクティブグラフ入りのHTMLレポートを1クリックでエクスポート。
9. **CSVテンプレートのダウンロード**:
   - 自社データ入力用の空のテンプレートCSV（UTF-8 BOM付き）をサイドバーからいつでもダウンロード可能。

## 🚀 クイックスタート

### 1. 必要要件
- Python 3.9 以上
- ライブラリ: `streamlit`, `plotly`, `pandas`, `requests`

```bash
pip install -r requirements.txt
```

### 2. 起動方法

#### Windowsの場合（どちらでも可）:
- `run.bat` をダブルクリック
- または PowerShell で実行:
  ```powershell
  .\run.ps1
  ```

#### コマンドラインから起動する場合:
```bash
python -m streamlit run app.py
```

ブラウザで自動的に `http://localhost:8501` が開きます。

## 📁 入力CSVフォーマット（`bidash` 完全互換）

文字コードは **UTF-8（BOM付き）**、UTF-8、または Shift-JIS（CP932）に対応しています。

1. **`input_pl.csv`**（損益計算書）
   - 1列目: `項目`
   - 2列目以降: 期名（最後の2列が「前期」「当期」として比較されます）
2. **`input_bs.csv`**（貸借対照表）
   - 1列目: `区分`（資産／負債／純資産）
   - 2列目: `項目`
   - 3列目以降: 期名
3. **`input_summary.csv`**（複数期サマリー）
   - 列名: `期`, `決算年月`, `売上高`, `経常利益`, `当期純利益`, `純資産`, `総資産`, `自己資本比率`, `ROE`, `EPS`
